# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Integration tests with Testcontainers PostgreSQL covering every filter, pagination and sorting, and comparing
  `GET /tasks` (Spring Specification Tools) with `GET /tasks/jpa-criteria` (JPA Criteria API) for each filter.
- `./mvnw spring-boot:test-run` runs the application against a PostgreSQL started by Testcontainers.
- Optional `sql` profile that logs the SQL generated by Hibernate and its parameters.
- GitHub Actions CI and Dependabot configuration.

### Changed

- **Breaking:** requires Java 21; upgraded to Spring Boot 4.1, Hibernate 7, Jakarta Persistence and
  Spring Specification Tools 1.0.0.
- **Breaking:** the page JSON is now `{"content": [...], "page": {"size", "number", "totalElements", "totalPages"}}`
  instead of the serialized `PageImpl`.
- **Breaking:** the database is PostgreSQL 17 in Docker Compose (`compose.yaml`, which replaces `docker-compose.yml`);
  the PostgreSQL 10 data directory in `.docker-volumes` must be removed.
- The tags of each task are returned sorted by id.
- SQL logging is off by default.
- OpenAPI documentation with springdoc-openapi 3, with filters and pagination documented as query parameters.
- The Docker image runs on Java 21 as a non-root user.
- Maven Wrapper 3.3.4 with Maven 3.9.

### Fixed

- `GET /tasks/jpa-criteria` returned a wrong `totalElements` when filtering by several tags across more than one page.
- `GET /tasks/jpa-criteria` failed with an internal error when only one of `descriptionOrTag.description` and
  `descriptionOrTag.tagDescription` was set.

### Removed

- ModelMapper and the unused generic CRUD service and repository layers.
